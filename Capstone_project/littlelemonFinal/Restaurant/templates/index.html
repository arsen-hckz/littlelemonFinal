About

The backend provides REST endpoints for menu and table reservations. Authentication is handled using token-based auth.

API Endpoints

Menu Items

GET /restaurant/api/menu-items/
POST /restaurant/api/menu-items/
GET /restaurant/api/menu-items/<id>/
PUT/PATCH/DELETE /restaurant/api/menu-items/<id>/

Bookings

GET /restaurant/booking/tables/
POST /restaurant/booking/tables/
GET /restaurant/booking/tables/<id>/
PUT/PATCH/DELETE /restaurant/booking/tables/<id>/

How to Test (Insomnia / Postman)

  1. Register a user: POST /auth/users/
  2. Obtain a token: POST /obtain-token/
  3. For protected endpoints, add header: Authorization: Token <your_token>
Tip: If you just want to show this page in a browser, go to /restaurant/ (or whatever URL you map to this template).
